# sets

Your places. One folder per set, same idea as `cast/`:

```
sets/<set-id>/
  set.json      id, the verbatim place description, lighting, time of day
  plate.png     the establishing image, no people in frame
  prompts.md    what made it
```

The plate is used as a Flow ingredient alongside the characters, and the description is pasted verbatim into every shot set there — so the light, the weather and the time of day stay the same across the whole video.
