# Brainstorming: questions and angles

## Ask only what is missing

Read everything the user already said first. Never re-ask what you were told. At most two rounds of `AskUserQuestion`, multiple choice, and always offer a "surprise me".

| Gap | Question | Options |
|---|---|---|
| Length | How long? | 15–20 s hook · 30 s standard reel · 45–60 s story |
| Shape | Where does it go? | reel / short (9:16) · YouTube (16:9) |
| Language | Which language? | English · Hindi · Hinglish · other |
| Tone | How should it feel? | funny · warm · dramatic · matter-of-fact |
| Cast | Who is in it? | one character to camera · two characters talking · a character and an object · nobody (places and narration) |
| Continuity | New or continuing? | brand-new characters · reuse someone from the library · a sequel to an earlier video |
| Look | Which look? | photoreal cinematic · stylised 3D · documentary / handheld · dreamy and soft |

If the user says "surprise me", pick the defaults that fail softest: 30 s, 9:16, two characters, photoreal cinematic, one set.

## Then three angles, not three wordings

Each angle must change something structural — who tells it, where it happens, what the turn is, or what form it takes (confession · argument · tutorial going wrong · countdown · overheard conversation · POV). If two angles would produce the same shot list, one of them is not an angle.

Three lines each:

```
A. <name>
   hook:   what the first two seconds show
   shape:  how it moves, in one sentence
   ending: what lands
```

Stop and let the user pick, or combine. Do not start writing prompts in the same breath.

## Things worth raising while brainstorming

- **An idea that needs crowds, vehicles at speed, readable on-screen text or a real person's likeness** should be reshaped now, before any credits go in. Veo spells badly and crowds drift.
- **More than two speaking characters** means more shots and more drift — suggest splitting the dialogue so one person speaks per shot.
- **A sequel** is cheaper and more impressive than a new world: the cast library already holds the faces. Offer it whenever it fits.
- **A line longer than about eighteen words** will not fit in an 8-second shot. Shorten it with the user while it is still a script.
